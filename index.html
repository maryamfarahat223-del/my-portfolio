NoDoze — Driver Drowsiness Detection

A real-time driver fatigue monitoring system built on a hybrid AI architecture, combining Deep Learning (CNN) with Fuzzy Inference Systems to detect drowsiness signs and trigger automated emergency workflows.

  • ▹ Facial Mesh Extraction: Utilizes MediaPipe to extract 468 facial landmarks for calculating Eye Aspect Ratio (EAR) and Mouth Aspect Ratio (MAR - Yawning).
  • ▹ Hybrid AI Architecture: Passes visual data to a PyTorch-trained CNN Classifier and fuses parameters using Fuzzy Logic to compute a precise fatigue index (0 to 1).
  • ▹ Smart Emergency Response: Classifies driver state into 3 tiers (Normal / Tired / Drowsy) to handle live audio alerts, WebSocket messaging, and auto-dispatching GPS coordinates to emergency contacts.
